# Play Console「資料安全性」表單答案

**你的應用程式是否會收集或分享任何必要的使用者資料類型？** → 是
（Google 定義：即使只在裝置上處理，讀取位置與通知內容仍建議如實申報為「收集」，但勾選「僅在裝置上處理」不會傳出）

| 資料類型 | 收集 | 分享 | 僅暫時處理 | 必要/選用 | 用途 |
|---|---|---|---|---|---|
| 位置 → 精確位置 | 是 | 否 | 否 | 選用 | 應用程式功能 |
| 財務資訊 → 購買記錄 | 是 | 否 | 否 | 必要 | 應用程式功能 |
| 應用程式資訊 → 其他使用者產生的內容（通知內容） | 是 | 否 | 是 | 必要 | 應用程式功能 |

- 資料是否經過傳輸加密？→ 不適用：資料不離開裝置（可選「否，資料未傳輸」相應選項）
- 使用者可否要求刪除資料？→ 是（App 內可刪除、解除安裝即全部刪除）

**應用程式內容 其他聲明**
- 廣告：不含廣告
- 目標年齡層：18 歲以上
- 新聞應用程式：否
- 健康應用程式：否
- 金融功能：個人記帳工具（不提供金融服務、不處理付款）

**權限說明（審查時若被詢問）**
- `BIND_NOTIFICATION_LISTENER_SERVICE`：核心功能 — 偵測錢包/銀行付款通知以觸發記帳提醒；App 內有顯著揭露對話框，使用者同意後才導向系統設定。
- `ACCESS_FINE_LOCATION`：僅於前景開啟填寫畫面時取得一次位置，作為消費地點；未申請背景位置。
- `POST_NOTIFICATIONS`：顯示記帳提醒。
